# MPC-002 — Canonical project read model v1 (SOURCE/QA ONLY)
Authority: root `SOURCE_OF_TRUTH.md` for Supervisor; each domain canonical SOT remains its own authority. This document is a schema contract, not a status claim.
## Contract
`src/control-center/project_read_model.mjs` exports `buildProjectReadModel(projects)`. Input is trusted revision-stamped discovery data, **not** execution authority. Structure: project > feature > task. Each projected node has `id`, `title`, `type`, `parentId`, `revision` (repo, SOT path, immutable SHA, URL), `evidence` entries (kind, verified, revision, URL), and independent `scopeStatus`, `transportStatus`, `ciStatus`, `releaseStatus`.
Scope: PLANNED, READY, IN_PROGRESS, BLOCKED, WAITING_OWNER, VERIFIED_DONE, UNKNOWN, CONFLICT. Unknown or unsupported states fail closed to UNKNOWN; different verified canonical revisions or competing scope claims produce CONFLICT. VERIFIED_DONE requires revision-aligned verified canonical_sot, task_dod, qa, and exact_main entries. Production acceptance is separately reported; neither heartbeat, CI success nor PR closure qualifies scope completion.
Evidence validation intentionally requires a named GitHub URL, immutable SHA and kind; it is **not** cryptographic verification. The future MPC-003 adapter must independently fetch and verify sources at their SHAs and handle staleness/main divergence. No fixture can establish production truth.
No network, API route, storage, Owner mutation, auth/session alteration, project selection, START/STOP, production dispatch, or deployment is implemented here. OPS-WebApp remains independently governed; aggregation is link-only.
QA contract: `node --test test/mpc002-project-read-model.test.mjs`. Test fixtures cover unknown, revision conflict, contradictory claims, incomplete proof, status separation, malformed input, and cross-repository isolation.
Release qualification remains subject to four hosted Supervisor workflows at exact PR SHA, independent review, merge, exact-main readback, and any separately authorized deployment gates.
